# Crypto Data Pipeline

A professional end-to-end data engineering and analytics project focused on cryptocurrency market data ingestion, orchestration, storage, transformation, and future machine learning integration.

## Technologies
* Python
* PostgreSQL
* Apache Airflow
* Docker & Docker Compose
* SQLAlchemy
* pandas
* Streamlit for dashboard visualization

## Goals
This project aims to simulate a real-world data platform capable of:

* Extracting cryptocurrency data from public APIs
* Automating ETL workflows with Airflow
* Storing historical market data
* Performing SQL-based transformations
* Generating analytical metrics
* Supporting dashboards and reporting
* Enabling future predictive ML models

## Data Source

This project uses the public CoinGecko API to retrieve cryptocurrency market data such as:
* Symbol
* Current price
* Market capitalization
* Trading volume
* Historical timestamps
